Welcome to the Tutorials section.

Tutorials are **learning-oriented** lessons that guide a newcomer through a complete end-to-end task. They are designed to help you get started with the project and build confidence.

* **[Getting Started](/tutorials/getting-started/):** Set up prerequisites, clone the monorepo, and run the core FBIT components locally.
* **[Make your first prototype change](/tutorials/prototype-kit/):** Run the FBIT prototype kit locally, add a design concept to a work item, and share it with the team.
