## Purpose

This plan defines the QA strategy to validate the Data Release for the **Section 251 (S251) covering the 2025-2026 period**, covering ingestion of the budget and outturn files, integration of the ancillary datasets (EHCP/SEN2, Statistical Neighbours, DSG, High Needs Place Numbers, ONS population, KS4/Attainment 8), and Local Authority (LA) level data accuracy in FBIT.

The calculation logic is unchanged from 2024-2025; the changes this release are to source file formats and schemas.

## Changes This Release

- Budget file is now `.ods` (`Planned_expenditure` sheet), previously CSV.
- Outturn file is now `.xlsx` (`LA_expenditure_by_year` sheet), previously CSV.
- High Needs Place Numbers file is now `.xlsx`, previously `.ods`.
- SEN2 source is `caseload.csv` (pivoted in memory); 2026 also combines the split `special_academy` and `special_free_school` columns.

## Scope

### In Scope

- Schema, format and structural validation of the budget and outturn workbooks and all ancillary datasets.
- SEN2 `caseload.csv` reshape and split-column combination validation.
- End-to-end pipeline run from raw file landing to database persistence.
- Data reconciliation of row counts, LA-identifier joins and sampled budget/outturn figures.
- Service/UI validation for the 2026 reporting year.
- Regression testing of historical S251 data (2025 and prior).
- Ancillary completeness reporting with year-on-year coverage comparison.

### Out of Scope

- Correctness of upstream raw data beyond schema/format.

## Test Activities

### Schema, Format and File Integrity

- Validate headers, data types and mandatory fields (LA codes, numeric values) against schema.
- Confirm every category-of-expenditure line is present with the exact configured label.
- Confirm `old_la_code`/`new_la_code` format and that the budget joins cleanly to the outturn.

### Ancillary Data and Completeness

- Validate the `caseload.csv` reshape and 2026 split special-school column combination; reconcile the EHCP breakdown to source.
- Validate schemas for Statistical Neighbours, DSG, High Needs Place Numbers and ONS population.
- Produce a completeness table of missing ancillary sets per LA.
- Compare LA counts and coverage (demographics, EHCP, pupils, SEN support, Attainment 8) against 2025.

### Pipeline

- Trigger ingestion in Test/Pre-Prod and monitor logs for silent drops, missing-column errors and failures.
- Confirm budget, outturn and ancillary data combine correctly, including DSG recoupment derivation.

### Database

- For a sample of 3 LAs, confirm `LocalAuthorityFinancial` budget/outturn figures match source with zero variance and that `BudgetTotalHighNeeds`/`OutturnTotalHighNeeds` reconcile.
- Confirm ancillary mappings are present in `LocalAuthorityNonFinancial`/`LocalAuthorityStatisticalNeighbours`.
- Compare LA counts and coverage (demographics, EHCP, pupils, SEN support, Attainment 8) for 2026 against 2025.
- Run regression checks on historical S251 data (2025 and prior).

### Service/UI

- Verify the 2026 toggle loads the correct LA dataset.
- Spot-check key metrics and filters (high-needs benchmarking) for a sample of LAs against source.
- Confirm missing ancillary data is handled gracefully.

## Responsibilities and Environment

### Responsibilities

| Role | Responsibility |
| :--- | :--- |
| **Data Analyst(s)** | Produce and review source S251 and ancillary files before the data release. |
| **Data Engineer** | Prepare files, configure reader settings/schemas, execute pipeline runs and provide logs. |
| **QA Lead** | Prepare test plans; manage execution of schema/format validation, completeness and UI checks. |
| **Engineer(s)** | Assist in test execution, running validation scripts and regression checks. |
| **Technical Lead** | Oversee the technical quality and integrity of the S251 ingestion pipeline. |
| **Stakeholders** | Conduct UAT and provide formal sign-off. |
| **Project Lead** | Final Go/No-Go decision for the S251 Data Release. |

### Environments

- **Test:** schema/format validation and full E2E ingestion with ancillary integration.
- **Pre-Prod:** final pipeline run with complete datasets, UAT and regression checks.

## Exit Criteria (Sign-off Requirements)

- [x] Budget/outturn formats, schemas, sheets, headers and category-line labels validated against the published 2026 files
- [x] Ancillary schemas validated, SEN2 `caseload.csv` reshape verified, and completeness summary produced
- [x] Pipeline completes E2E with no High or Critical errors
- [x] Database reflects accurate 2025-2026 S251 data with zero-variance budget/outturn sample checks
- [x] UI/Service displays S251 data correctly for the 2026 year
- [x] Regression tests confirm no degradation of historical data (2025 and prior)
- [x] Product Owner/BA sign-off received
