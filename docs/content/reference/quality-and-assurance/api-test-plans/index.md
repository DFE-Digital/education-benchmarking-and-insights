Technical test plans, endpoint validation rules, and scenario coverage specifications for platform APIs.

## Local Authority API Endpoints

* **[LocalAuthority - Accounts](/reference/quality-and-assurance/api-test-plans/localauthority-accounts/):** Local authority accounting return and expenditure endpoint tests.
* **[LocalAuthority - Details](/reference/quality-and-assurance/api-test-plans/localauthority-details/):** LA metadata, code lookup, and operational status tests.
* **[LocalAuthority - EducationHealthCarePlans](/reference/quality-and-assurance/api-test-plans/localauthority-educationhealthcareplans/):** EHCP caseload and placement query tests.
* **[LocalAuthority - HealthCheck](/reference/quality-and-assurance/api-test-plans/localauthority-healthcheck/):** Heartbeat and dependency connectivity validation.
* **[LocalAuthority - Search](/reference/quality-and-assurance/api-test-plans/localauthority-search/):** Predictive text search and code lookup tests.
* **[LocalAuthority - StatisticalNeighbours](/reference/quality-and-assurance/api-test-plans/localauthority-statisticalneighbours/):** Statistical neighbour comparator calculation tests.

## School API Endpoints

* **[School - Accounts](/reference/quality-and-assurance/api-test-plans/school-accounts/):** School-level financial accounts, balances, and expenditure tests.
* **[School - Census](/reference/quality-and-assurance/api-test-plans/school-census/):** Pupil headcount, FSM eligibility, and demographic query tests.
* **[School - Comparators](/reference/quality-and-assurance/api-test-plans/school-comparators/):** Pre-computed top-30 statistical comparator sets endpoint tests.
* **[School - Details](/reference/quality-and-assurance/api-test-plans/school-details/):** URN lookup, GIAS attributes, and governance status tests.
* **[School - HealthCheck](/reference/quality-and-assurance/api-test-plans/school-healthcheck/):** Operational readiness probe validation.
* **[School - MetricRagRatings](/reference/quality-and-assurance/api-test-plans/school-metricragratings/):** Cost category RAG ratings (Red, Amber, Green) retrieval tests.
* **[School - Search](/reference/quality-and-assurance/api-test-plans/school-search/):** School name, URN, and postcode auto-complete tests.
