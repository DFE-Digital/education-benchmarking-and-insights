Procedures for managing live service operations, incident triage, alerting, secrets, and reporting:

* **[Incident Management](/how-to/infrastructure-and-operations/incident-management/):** Triage severity levels, notification cadence, and remediation steps during live service incidents.
* **[Monitoring and Alerting](/how-to/infrastructure-and-operations/monitoring-alerting/):** Monitor application performance, track metric alerts, and inspect telemetry in Application Insights.
* **[Monthly Reporting](/how-to/infrastructure-and-operations/monthly-reporting/):** Generate monthly service usage and school engagement reports using Power Query and Azure SQL.
* **[Release Communications](/how-to/infrastructure-and-operations/release-communications/):** Prepare and distribute release broadcast communications to stakeholders.
* **[Root Cause Analysis](/how-to/infrastructure-and-operations/root-cause-analysis/):** Conduct blameless post-incident reviews using the standardised RCA template.
* **[Runbooks](/how-to/infrastructure-and-operations/runbooks/):** Operational runbooks for backups, disaster recovery, service shuttering, and deployment operations.
* **[Secret Management](/how-to/infrastructure-and-operations/secret-management/):** Safely handle credentials, encrypt local Function App settings, and configure .NET User Secrets.
