Welcome to the technical documentation for the Financial Benchmarking and Insights Tool (FBIT).

Financial Benchmarking and Insights Tool is a service designed to help schools, academy trusts, and local authorities in England compare their financial data with similar establishments. Its primary purpose is to empower educational leaders to make informed financial decisions, identify areas for potential savings, and optimise resource allocation to improve outcomes for pupils.

## Documentation Structure

This documentation site is organised according to the [Diátaxis framework](https://diataxis.fr/), separating content into four distinct quadrants based on what you need to achieve:

1. [Tutorials](/tutorials/) (Learning-oriented): End-to-end lessons that guide new contributors through a complete task to build early confidence.
2. [How-to guides](/how-to/) (Task-oriented): Practical, step-by-step recipes that help you solve specific, real-world problems.
3. [Reference](/reference/) (Information-oriented): Precise, structured descriptions of the underlying system, technical details, APIs, and schemas.
4. [Explanation](/explanation/) (Understanding-oriented): Discussions and deep dives that explain why things are structured the way they are, including design principles and architectural context.
