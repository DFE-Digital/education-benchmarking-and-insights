## What Happened

We established a standard Value Rule Set for the Financial Benchmarking and Insights Tool (FBIT) to evaluate whether proposed data and product features deliver sufficient organisational value to proceed to implementation.

## Key points

Evaluate all proposed FBIT features against four core value drivers:
1. **Outcome and Financial Insight Alignment**: Does the feature help schools, trusts, or Local Authorities compare financial resource use with pupil outcomes?
2. **Data Integrity and Historical Continuity**: Does the feature preserve backward compatibility across prior reporting runs while introducing new annual metrics?
3. **Accountability and Oversight Support**: Does the feature provide accurate, official Department for Education (DfE) benchmark figures (such as Local Authority and National averages) for governors, trustees, and Local Authority analysts?
4. **Operational Maintainability**: Can the feature integrate cleanly into the automated annual data pipeline without manual intervention?

## Why It Matters

FBIT serves national education stakeholders who rely on consistent annual datasets. Features that break historical pipeline runs or fail to align with official DfE statistical publications reduce trust and cause operational outages during annual data releases.

## Applies When

Use this Value Rule Set when assessing new features or data pipeline enhancements via the `feature` and `value` skills.
